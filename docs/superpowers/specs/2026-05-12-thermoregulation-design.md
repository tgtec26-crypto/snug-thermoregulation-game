## 1. 개요

**체온 조절 RPG**는 중학교 3학년 학생이 「체온 조절」 단원의 학습 후 **정리·심화 활동**으로 사용하는 인터랙티브 학습 게임이다. 학생은 수학여행 캐릭터가 되어 한국에서 출발해 추운 나라 1곳과 더운 나라 1곳을 방문하며, 각 환경에서 자기 몸의 체온 조절 반응(혈관 수축/확장·근육 떨림·땀·기화열·티록신)을 직접 다루는 흐름을 통해 항상성 개념을 적용·평가한다.

### 1.1 사전 학습 (게임 외부)
- 항상성 개념과 체온 조절 메커니즘 (혈관 수축/확장, 근육 떨림, 땀·기화열, 티록신)
- 신경 작용(빠름·일시적) vs 호르몬 작용(느림·지속적) 비교
- 4종 교과서 공통 핵심 개념 학습 완료 가정

### 1.2 게임 활용 시나리오
- 사전 학습 완료 후 1차시(30~40분)에 사용하는 정리·심화 활동
- 가정 자유 시간 재플레이 가능 (자유 모드는 별도 진행, 본 게임은 정리·심화에 집중)

## 2. 학습 목표

| 목표 | 게임에서 달성 |
|------|--------------|
| 추울 때 신체 반응(혈관 수축·근육 떨림·티록신↑) 식별·적용 | 추운 나라 야외 location의 미니 액션 + HUD 슬라이더 관측 |
| 더울 때 신체 반응(혈관 확장·땀 분비·기화열) 식별·적용 | 더운 나라 야외 + 추운 나라 실내 사우나의 미니 액션 |
| 신경 작용 vs 호르몬 작용의 시간차 인식 | HUD의 토스트(즉시) vs 티록신 게이지(느림) 시각화 |
| 항상성의 정의("정상 범위 유지")를 메커니즘으로 체화 | 체온 막대 슬라이더를 녹색대(35.5~37.5℃)에 유지하는 게임플레이 |
| 체온 외 다른 항상성(혈당·수분량)으로의 일반화 | 결말 교실 멘트 |

## 3. 게임 컨셉

### 3.1 비주얼 스타일
- **2D 도트(픽셀아트) RPG** — `snug-hormone-game`·`pizza-expedition`과 동일 톤
- **화면당 배경 1장** (1280×800 도트 일러스트 PNG, 사용자 직접 제작)
- **타일맵 없음** — 배경 위에 캐릭터 sprite를 얹고 노드 좌표 사이를 L자(맨해튼) 경로로 이동
- **동적 효과**: Phaser 파티클로 눈·김·땀·오로라 등 환경 효과 오버레이

### 3.2 캐릭터·내러티브
- **플레이어**: 사대부여중 학생 (수학여행 컨셉, 신규 sprite). idle 1프레임 + 4방향 walk 각 5프레임 (~110×186 픽셀 권장)
- **학급 친구 NPC 4명**: 시작 교실에서 가위바위보 상대 (4국 각 1명씩 배정)
- **공항 직원 NPC 3명**: 출발국·1국·2국 공항에서 퀴즈 출제
- **환경 가이드 NPC**: 각 location에 0~1명 (사우나 주인, 핫스프링 안내원 등 — 최소화)

### 3.3 입력 환경
- **타깃 기기**: 크롬북 1280×800 (16:10)
- **입력 우선순위**: 1급 마우스/터치 클릭, 2급 키보드(선택지 1~4 단축키)

## 4. 게임 흐름 (Game Flow)

### 4.1 전체 플로우 (MVP 기준, 2국 미션)

```
[타이틀] 닉네임 입력 → [시작]
   ↓
[교실 — 학급 회의]
  ① 추운 나라 2개 중 1개 선택 (핀란드 / 캐나다)
  ② 더운 나라 2개 중 1개 선택 (UAE 두바이 / 이집트)
  ③ 추 가위바위보 1회 → 승: 본인 선택 / 패: NPC 선택
  ④ 더 가위바위보 1회 → 승: 본인 선택 / 패: NPC 선택
  → 1국·2국 확정 (4가지 조합 가능)
   ↓
[출발국 공항] 퀴즈 1문항 (정답까지 다른 문항 반복 출제) → 비행기표
   ↓
[월드맵] 비행기 컷씬 (출발국 → 1국 공항)
   ↓
   ┌─────── 1국 사이클 ───────┐
   │                          │
   ▼                          │
[1국 공항 도착]                │
   ↓                          │
[1국 야외] 환경 노출 + 미니 액션 + HUD 막대 관측 │
   ↓                          │
[1국 실내 — 패러독스] 반대 환경 + 반대 미니 액션 │
   ↓                          │
[1국 공항] 퀴즈 1문항 → 비행기표 │
   ↓ [월드맵 비행기 컷씬: 1국 → 2국] │
   └──── (2국 사이클 동일) ────┘
   ↓
[2국 공항] 퀴즈 1문항 → 비행기표
   ↓
[월드맵 비행기 컷씬: 2국 → 출발국]
   ↓
[교실 — 결말]
  - 체온 유지율 + 퀴즈 정답률 → ⭐ 별점
  - 학습 정리 멘트: "수학여행에서 체온 조절(항상성)의 중요성을 알게 되었다"
  - 일반화 한 마디: "혈당량·수분량 등 다른 항상성도 같은 원리"
  - 보너스 진입 안내 (Polish 단계): "다른 나라도 더 가볼래?"
```

### 4.2 핵심 룰

| 룰 | 동작 |
|----|------|
| **순서 고정** | 추운 나라(1국) → 더운 나라(2국). 학급회의로 어느 추/어느 더인지 결정 |
| **공항 퀴즈 오답 처리** | 1차 오답 → 다른 문항 출제 → 또 오답이면 또 다른 문항... 정답까지 반복. 영구 막힘 없음 |
| **미니 액션 실패** | 실패해도 진행. 체온이 위험 범위 진입 → 토스트 경고 + NPC 도움 (자동 회복) |
| **게임오버 없음** | 모든 학생이 결말까지 도달 보장 (Q7 C) |
| **저장** | localStorage `{nickname, phase, chosenCold, chosenHot, completedCountries, currentTemp, quizScore, characterPos}` 새로고침 시 이어서 진행 |

## 5. HUD 시스템 (Q5 v2)

### 5.1 레이아웃
- **위치**: 화면 우측 사이드바, 폭 ~110px (≈8.6%), 높이 ~85%
- **게임 영역**: 좌측 약 91%

### 5.2 체온 막대 (메인 시각 요소)
- **색상 영역**:
  - 🔵 저체온 (33~35.5℃)
  - 🟢 적정 (35.5~37.5℃)
  - 🔴 고체온 (37.5~40℃)
- **눈금 표시값**: 33, 35, 35.5, 36.5, 37.5, 38, 40
- **슬라이더(◀)**: 현재 체온을 실시간 트윈으로 표시
- **readout**: "35.8℃ — 저체온 진입!" 같은 수치+상태 라벨

### 5.3 보조 인디케이터 (체온 막대 아래)
- 🩸 **혈관**: ▼ 수축 / ▲ 확장 — 텍스트 chip (즉시 변함)
- 💧 **땀**: 0~100% 가로 게이지 — 빠르게 차오름·줄어듦
- ⚗️ **티록신**: 0~100% 가로 게이지 — 느리게 차오름 (호르몬 시간차 시각화)

### 5.4 변화 로그 (HUD 하단)
- 두 줄 형식: "방금: 떨림 발생" / "다음: 티록신 효과 (느림)"
- 즉시 반응(신경)과 느린 반응(호르몬) 대비 강조

### 5.5 토스트 알림 (게임 영역 상단 중앙)
- 변화 순간만 짧게(2~3초) 표시
- 예: "🩸 혈관 수축! 체온 방어 시작" / "💧 땀 분비 시작! 기화열로 발산"

### 5.6 mockup 참고
- v1 (참고용, 폐기): `docs/brainstorm-mockups/q5-hud-v1-top.html` — Q5 1차 결정 시 상단 미니 HUD 안

## 6. 체온 게이지 시스템 (Q7 C)

### 6.1 기본 원리
- 체온은 **실제 게임 변수** (0.1℃ 단위, 36.5℃ 시작)
- 환경(추위/더위) + 학생 액션(미니게임 성공/실패) + 시간 경과에 따라 상승·하강
- 위험 범위(< 35.5℃ 또는 > 37.5℃) 진입 → 경고 토스트 + NPC 도움 / 자동 회복 트리거
- **게임오버 없음**

### 6.2 환경별 기본 체온 변화율 (개략, 구현 시 조정 필요)
| 환경 | 기본 변화율 | 비고 |
|---|---|---|
| 추운 야외 (-15~-30℃) | -0.05℃/초 | 떨림 미니게임 성공 시 회복 |
| 추운 실내(사우나) +85℃ | +0.08℃/초 | 땀 닦기 미니게임 성공 시 회복 |
| 더운 야외 (+40~+45℃) | +0.05℃/초 | 땀·그늘 찾기 미니게임 성공 시 회복 |
| 더운 실내(스키두바이) -3℃ | -0.04℃/초 | 떨림 미니게임 성공 시 회복 |
| 일반 환경 (공항·교실) | 0 (안정) | — |

### 6.3 학생 액션 효과
- 미니게임 성공 → 체온 +0.3℃ 또는 -0.3℃ (방향은 환경에 맞춰 자동 결정)
- 미니게임 실패 → 변화 없음 (체온 그대로 표류, 환경 변화율 계속 적용)
- **유지 점수 누적**: 매 틱 슬라이더가 적정 녹색대(35.5~37.5℃)에 있으면 `inSafeZoneTicks += 1`, `totalTicks += 1`. 결말의 "체온 유지율 = inSafeZoneTicks / totalTicks"

### 6.4 위험 범위 자동 회복
- 슬라이더가 녹색대 밖으로 벗어나면 토스트: "어지러움! 다음 액션이 필요해요" 또는 "NPC가 손난로(또는 부채)를 줍니다"
- 3~5초 카운트 후 자동 보정 (0.2~0.3℃ 회복)
- 학생이 그 사이 미니게임 성공 → 더 큰 회복 + "유지 점수" 보너스

### 6.5 결말 평가
- **체온 유지율**: 게임 시간 중 슬라이더가 적정 녹색대에 머문 비율 (%)
- **퀴즈 정답률**: 공항 3문항 중 첫 시도 정답 비율
- **별점 산출 (초기값, 구현 후 실제 플레이 기준으로 튜닝 가능)**:
  - ⭐⭐⭐: 체온 유지율 ≥80% AND 퀴즈 첫시도 정답률 100% — "체온 유지의 달인"
  - ⭐⭐: 체온 유지율 ≥60% OR 퀴즈 첫시도 정답률 ≥66% — "체온 조절 능숙"
  - ⭐: 그 외 (모든 학생 최소 1점) — 격려 메시지 "체온 조절은 어렵지만, 우리 몸은 끝까지 노력했어요"

## 7. 4개국 디자인 (Q9)

### 7.1 4국 확정 (세트 B 안전 보수)
| 분류 | 국가 | 야외 | 실내 (패러독스) | 배경 시각 차별화 |
|---|---|---|---|---|
| 추 1 | 🇫🇮 핀란드 라플란드 | -15℃ 시내·자작나무 숲 | 사우나 +85℃ | 눈·자작나무·통나무집 |
| 추 2 | 🇨🇦 캐나다 옐로나이프 | -30℃ 호숫가, 오로라 | 노천 핫스프링 +38℃ | 오로라·눈·캠프파이어 |
| 더 1 | 🇦🇪 UAE 두바이 | 사막 +45℃ | 스키두바이 -3℃ | 모래·낙타·초고층 빌딩 |
| 더 2 | 🇪🇬 이집트 카이로/기자 | 피라미드 사막 +40℃ | 알렉산드리아 카타콤 또는 박물관 (시원) | 피라미드·스핑크스·야자수 |

### 7.2 가위바위보 매칭
- **추 가위바위보 NPC**: 핀란드 학생 또는 캐나다 학생 (플레이어가 안 고른 쪽)
- **더 가위바위보 NPC**: 두바이 학생 또는 이집트 학생 (플레이어가 안 고른 쪽)
- 결과 4가지 조합 가능:

| 추 결과 | 더 결과 | 학생이 가는 1국·2국 |
|---|---|---|
| 승 | 승 | 본인 선택 추 + 본인 선택 더 |
| 승 | 패 | 본인 선택 추 + NPC 선택 더 |
| 패 | 승 | NPC 선택 추 + 본인 선택 더 |
| 패 | 패 | NPC 선택 추 + NPC 선택 더 |

### 7.3 미니 액션 — 국가 무관 공통 패턴 (MVP)
- **추운 환경 (1국 야외 + 2국 실내 스키두바이/스키장)**: 떨림 리듬 미니게임 (좌/우 또는 ASDF 키 리듬 탭으로 떨림 시뮬레이션 → 열 발생)
- **더운 환경 (1국 실내 사우나/핫스프링 + 2국 야외 사막)**: 땀 닦기 탭 미니게임 (화면 위 땀 방울을 빠르게 클릭 → 기화열 발산 가속)

> 국가별 차별화는 Phase 2(문화 미니 이벤트)에서 추가, MVP는 공통 패턴 통일

### 7.4 환경별 시각 효과 (Phaser 파티클)
| 환경 | 파티클 효과 |
|---|---|
| 추운 야외 | 눈 떨어짐, 입김(흰 김) |
| 사우나·핫스프링 | 김 피어오름 |
| 사막 야외 | 모래 바람, 아지랑이 |
| 스키두바이 | 눈 입자, 푸른 톤 안개 |

## 8. 공항 퀴즈 시스템 (Q6)

### 8.1 구조
- **3공항**: 출발국 공항, 1국 공항, 2국 공항
- **공항당 출제**: 1문항씩 (정답까지 다른 문항 반복 출제)
- **총 풀**: 문제 은행 약 15~20문항 (체온 조절 핵심 개념 커버)

### 8.2 출제 방식
- 문제 은행에서 무작위 선택
- 학생이 오답 → 다음에는 **다른 문항** (같은 문항 반복 X) 출제
- 정답까지 반복 → 학생이 반드시 한 번은 정답을 맞춰야 통과

### 8.3 문제 풀 카테고리 (각 5~7문항 권장)
1. **추울 때 반응** (혈관 수축, 근육 떨림, 티록신)
2. **더울 때 반응** (혈관 확장, 땀, 기화열)
3. **신경 vs 호르몬 비교** (빠름/느림, 일시적/지속적)

### 8.4 문항 형식
- 4지선다 객관식
- 짧고 명확한 문항 (정리·심화용)
- 정답 선택 시 짧은 해설 1줄 ("👍 혈관이 수축해서 표면 열 손실을 줄여요")

### 8.5 데이터 위치
- `public/data/quiz-pool.json` (admin 모드에서 편집 가능)

## 9. 노드 기반 이동 시스템 (Q8)

### 9.1 location 노드
- 각 1280×800 배경 도트 일러스트 위에 **클릭 가능한 노드** 좌표를 배치
- 노드 = "캐릭터가 도착해서 이벤트가 발생하는 점"
- L자 경로 자동 이동 트윈 (snug-hormone-game CityMapScene 패턴)

### 9.2 노드 종류 (개략)
- **공항 노드**: 퀴즈 게이트
- **야외 노드**: 미니게임 + HUD 관측
- **실내 노드**: 미니게임 + HUD 관측 (반대 환경)
- **NPC 노드**: 대화 박스 (학급 친구, 가이드 NPC)
- **출입 노드**: 다음 location으로 이동 트리거 (예: 공항 → 비행기 컷씬)

### 9.3 좌표 저장
- `public/data/nodes-<scene>.json` (예: `nodes-finland-outdoor.json`)
- 각 노드: `{id, x, y, type, action}`
- `?admin=1` 시각 편집 모드: 마우스 드래그 → 좌표 자동 저장 (작업 효율 핵심)

## 10. 기술 아키텍처

### 10.1 스택
| 항목 | 선택 | 이유 |
|------|------|------|
| 프레임워크 | Next.js 16 (App Router) | 자매 프로젝트 통일, Vercel 자동 배포 |
| 게임 엔진 | Phaser 4 | `import * as Phaser from 'phaser'` |
| 언어 | TypeScript | 게임 상태 타입 안전성 |
| 스타일 | Tailwind CSS 4 | UI 빠른 작성 |
| 상태 관리 | Zustand (persist) | Phaser ↔ React 양쪽 store 공유, localStorage 자동 동기화 |
| 테스트 | Vitest | 단위·통합 테스트 |
| 패키지 매니저 | pnpm | 자매 프로젝트 통일 |
| 배포 | Vercel (GitHub 자동) | 푸시 즉시 반영 |

### 10.2 Phaser ↔ React 분담

| 영역 | 담당 |
|---|---|
| 배경 도트 일러스트 + 캐릭터 sprite + L자 이동 트윈 + 파티클 효과 | **Phaser** (각 SceneXxx) |
| HUD (체온 막대 + 보조 인디케이터 + 토스트) | **React 오버레이** |
| 대화 박스, 퀴즈 UI, 미니게임 UI, 학급회의/결말 화면 | **React 오버레이** |
| phase 머신 + 진행 상태 (체온 변수 포함) | **Zustand store** |

### 10.3 Scene 구조 (Phaser)

```
BootScene             → 자산·JSON·폰트 프리로드
TitleScene            → 닉네임 입력 + 시작 버튼
ClassroomScene        → 시작 학급 회의 (선택 + 가위바위보)
AirportScene          → 출발국·1국·2국 공항 (퀴즈 게이트)
WorldMapScene         → 비행기 이동 컷씬
CountryScene          → 1국·2국 (야외/실내 노드 전환)
EndingScene           → 결말 교실 + 별점 평가
```

> 4개국 각각 별 Scene이 아니라 `CountryScene` 하나가 `currentCountry` 상태에 따라 다른 배경·노드를 로드. 그러면 4개국 자유 방문(Polish 단계 보너스 포함)도 쉽게 확장됨.

### 10.4 React 컴포넌트 구조

```
app/
  layout.tsx
  page.tsx       — <PhaserCanvas /> + <UIOverlay />
components/
  PhaserCanvas.tsx
  UIOverlay.tsx  — 현재 phase에 따라 아래 중 하나 렌더
    HUDBar.tsx        (게임 진행 중 항상 표시)
    DialogBox.tsx     (NPC 대화)
    QuizModal.tsx     (공항 퀴즈)
    MinigameModal.tsx (떨림/땀 닦기)
    ClassroomChoice.tsx (학급회의 선택)
    RPSModal.tsx      (가위바위보)
    EndingCard.tsx    (별점 평가)
```

## 11. 데이터 구조

### 11.1 Zustand store (요지)

```typescript
type Phase =
  | 'title' | 'classroom' | 'rps_cold' | 'rps_hot'
  | 'airport_start' | 'worldmap_1' | 'country_1_outdoor' | 'country_1_indoor'
  | 'airport_1' | 'worldmap_2' | 'country_2_outdoor' | 'country_2_indoor'
  | 'airport_2' | 'worldmap_3' | 'ending'
  | 'bonus_select' | 'bonus_country' // Polish 단계

type Country = 'finland' | 'canada' | 'dubai' | 'egypt'

interface GameState {
  // 식별
  nickname: string

  // 진행 상태
  phase: Phase
  chosenCold: Country       // 학생이 고른 추운 나라
  chosenHot: Country        // 학생이 고른 더운 나라
  actualCold: Country       // 가위바위보 결과 실제 행선지
  actualHot: Country
  completedCountries: Country[]

  // 체온 시스템
  currentTemp: number       // 0.1℃ 단위
  inSafeZoneTicks: number   // 적정 녹색대 머문 틱 수
  totalTicks: number

  // 보조 인디케이터
  vesselState: 'constricted' | 'normal' | 'dilated'
  sweatLevel: number        // 0~100
  thyroxineLevel: number    // 0~100

  // 퀴즈
  airportQuizAttempts: { [airport: string]: number }  // 첫 시도 정답 추적용
  airportQuizCorrect: number  // 첫 시도 정답 수

  // 위치 (저장/복원)
  characterPos: { x: number, y: number }

  // 액션
  setPhase: (p: Phase) => void
  adjustTemp: (delta: number) => void
  // ...
}
```

### 11.2 정적 데이터 파일 (public/data/)

| 파일 | 내용 |
|---|---|
| `quiz-pool.json` | 공항 퀴즈 문제 은행 (15~20문항, 카테고리 태그 포함) |
| `nodes-<scene>.json` | 각 Scene의 노드 좌표 (`?admin=1`에서 편집) |
| `country-config.json` | 4국 메타데이터 (이름·국기·환경 온도·실내 패러독스 정보 등) |
| `dialogue-<scene>.json` | NPC 대사 (학급 친구, 가이드 NPC 등) |
