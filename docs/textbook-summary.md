## 1. 공통 핵심 개념 (4종 모두 일치)

| 항목 | 내용 |

| **더울 때 반응** | ① 피부 혈관 확장 → 열 발산 증가 / ② 땀 분비 증가 (기화열로 체온 하강) |

## 3. 출판사별 본문 요지

### 비상
- 도입: **찜질방 사례**(땀↔떨림)
- 정상 체온 **37℃** 명시
- 신경 작용·호르몬 작용을 더울 때/추울 때 도식으로 분리
- 활동: 4컷 만화로 표현
- 특이점: "**어린아이**는 티록신 작용으로 체온을 조절"이라고 한정 서술
- 기화열 개념 박스 제공

### 천재
- 도입: **교실 자동 온도 조절기** 비유
- 신경(빠름·좁음·일시적) vs 호르몬(느림·넓음·지속적) **비교 강조**
- 탐구가 **추울 때만** 제시되고 더울 때는 **추론하기** 활동
- 특이점: **갑상샘 자극 호르몬**(뇌하수체→갑상샘) 경로 명시, **털 주변 근육 수축**(입모근) 언급
- 응용: 갑상샘 기능 저하증 → 추위 잘 탐 (티록신 연결)

### 동아
- 도입: **90℃ 찜질방 체온 예측**
- 가장 상세한 조절 경로 흐름도: 피부(냉점) → 간뇌 → ① 신경(피부 혈관 수축) ② 호르몬(뇌하수체→갑상샘 자극 호르몬→갑상샘→티록신→세포 호흡 촉진)
- 추울 때/더울 때 비교 정리표 제공 (열 발산·열 발생·피부 근처 혈관)
- 시각적 연결: 겨울 얼굴 창백 ↔ 여름 얼굴 붉어짐
- 특이점: **냉점**(감각점) 용어 사용

### 미래엔
- 도입: **운동 시 땀 분비**
- 경로: 피부 → 신경계 → 간뇌 → 신경+호르몬
- **기화열 개념 박스**로 별도 설명 (땀=물, 증발 시 열 흡수)
- 통합자료실에서 **항이뇨 호르몬에 의한 수분량 조절**까지 확장 (체온 조절 단원에 인접 배치)
- 특이점: 4종 중 **티록신을 체온 조절 본문에 직접 명시하지 않음** (혈관 수축/근육 떨림/땀 중심); 호르몬에 의한 세포 호흡 조절은 일반론 수준
- 평가: "더울 때 얼굴이 빨갛게 되는 까닭" 서술형

## 4. 게임 콘텐츠 설계 시사점

- **공통 핵심**(혈관 수축/확장 + 근육 떨림 + 땀·기화열 + 티록신)을 게임의 척추로 잡는다
- 출판사별 차이점은 **보너스/심화 콘텐츠**(예: 입모근, 냉점, 갑상샘 자극 호르몬 경로)로 활용 가능
- "신경 = 빠름 / 호르몬 = 느림" 비교는 게임 메커니즘 자체에 녹일 수 있음 (한 야외 위치에서 도착 즉시 = 신경 / 잠시 후 = 호르몬)
- 결말 컷씬에서 "혈당량·수분량 등 다른 항상성에도 같은 원리" 한 마디 → 4종 교과서 모두에 부합
