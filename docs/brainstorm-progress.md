## 1. 사용자 원안 (요약)

- 2D 도트 형식 RPG + 퀴즈 + 미니게임
- 학생이 **추운 나라**(예: 핀란드)와 **더운 나라**(예: 두바이)를 여행
- 추운 나라 안의 **사우나/찜질방**, 더운 나라 안의 **실내 스키장** 같은 패러독스 환경 포함
- 비행기/자동차 이동 시 **퀴즈/미니게임**
- 추운 나라 1개 + 더운 나라 1개 방문 = **미션 성공**

## 2. 결정 사항 (Q1~Q3)

### ✅ Q1. 게임의 수업 내 위치
**B = 단원 정리/심화 차시** (본 학습 후 적용 활동)

- 학생은 이미 핵심 개념(혈관 수축/확장, 근육 떨림, 땀·기화열, 티록신 등)을 한 번 학습한 상태
- C(자유 사용/숙제)는 별도 자율 진행으로 처리하므로 본 게임은 정리·심화 한 곳에 집중

### ✅ Q2. 학습 범위
**D = 체온 조절만 + 결말부에서 항상성 개념으로 일반화**

- 혈당량 조절은 `snug-online-office` 시뮬레이터가 담당 → 게임 내에서 다루지 않음
- 게임은 체온 조절에 집중
- **결말 컷씬에서 한 마디로** "이 게임에서 본 원리는 혈당량·수분량 등 다른 항상성에도 동일 적용된다" 라고 일반화 → 4교과서가 강조하는 상위 개념(항상성) 잡아주기

### ✅ Q3. 국가 구성
**A + b 조합**

- A: 추운 2 + 더운 2 = **4개국**, 국가별 **고유 시나리오**
- b: 2개국(추운 1 + 더운 1) 클리어 시 **미션 완료** + 나머지 2개국은 **보너스 자율 방문 가능**

근거:
- 호르몬 원정대(환자 4명)와 동일한 "4개 사이클" 분량 → 작업량 가늠 쉬움
- 친구 간에 다른 국가 조합으로 플레이 가능 → 자율 학습 시 재플레이성 ↑
- 국가별 고유 시나리오로 흥미 ↑ (핀란드 사우나 vs 러시아 노천온천, 두바이 실내 스키장 vs 사우디 실내 워터파크 등)

## 3. ✅ Q4 — 한 국가 방문의 흐름 구조

**A 압축형 (3 stops: 공항 → 야외 → 실내, ~5분/국)** 선택.

근거:
- 학습 효과 / 작업량 / 1차시 적합성 모두 가장 균형 잡힘
- 야외 한 곳에서 시간 경과를 시각 효과로 표현 → "신경은 빠름 / 호르몬은 느림" 비교가 게임 메커니즘 자체로 학습됨
- 2국가만 가도 ~10분, 4국가 다 가도 ~20분 → 자연스러운 난이도 곡선
- C의 "추→더→추 전환 강조"는 결말 컷씬의 한 마디로 대체 가능

### (참고) 옵션 비교

**한 국가를 방문하는 동안 학생이 거치는 단계 수**를 결정해야 합니다.

| 옵션 | Stops | 1국가 시간 | 2국가 클리어 | 콘텐츠 부담 |
|---|---|---|---|---|
| **A 압축형** | 3 (공항 → 야외 → 실내) | ~5분 | ~10분 | 낮음 |
| **B 분리형** | 4 (야외에서 신경/호르몬 분리) | ~7~8분 | ~15분 | 중간 |
| **C 왕복형** | 5 (실내 후 야외 복귀로 전환 강조) | ~8~10분 | ~18분 | 중상 |

### 옵션 상세

**A 압축형 (Claude 추천)**
```
✈️ 공항 도착 → 🏔️ 시내 광장(-15℃)                  → ♨️ 사우나(90℃) → ✈️ 출국
              "도착 즉시: 떨림+혈관 수축(신경)"      "혈관 확장+땀
              "잠시 후:   티록신↑ → 세포 호흡↑(호르몬)" 분비 = 반대 환경 반응"
```
- 야외 한 곳에서 **시간 경과를 시각 효과로 표현** → 교과서가 강조하는 "신경은 빠름 / 호르몬은 느림" 비교가 게임 메커니즘 자체로 학습됨
- 1차시 30~40분 안에 4국가 다 가도 여유 있음
- 2국가만 가도 ~10분 → 학생 좌절 없고, 보너스로 4국가 다 가면 ~20분 → 자연스러운 난이도 곡선

**B 분리형**
```
✈️ 공항 → 🏔️ 시내(신경 반응) → ❄️ 호숫가(호르몬 반응) → ♨️ 사우나 → ✈️ 출국
```
- 신경/호르몬 학습 비트가 또렷이 분리되지만, 야외 2번째 location의 작업량 ↑

**C 왕복형**
```
✈️ 공항 → 🏔️ 시내 → ♨️ 사우나 → 🏔️ 시내 복귀(다시 추위 반응) → ✈️ 출국
```
- "추위 → 더위 → 추위" 의 이중 항상성 전환을 강조하지만 분량 ↑

### Claude 권장
**A (압축형)**. 학습 효과 / 작업량 / 1차시 적합성 모두 가장 균형 잡힘. C의 "전환 강조"는 결말 컷씬의 한 마디로 대체 가능.

mockup HTML은 [brainstorm-mockups/q4-country-flow.html](brainstorm-mockups/q4-country-flow.html) 에 보관 — 다른 기기에서 브라우저로 직접 열어볼 수 있음.

## 3-1. ✅ Q5 — 학습 시각화/HUD (v2 확정)

**우측 사이드 세로 막대형 HUD + 토스트 알림 + 보조 인디케이터.** snug-online-office 혈당량 시뮬과 같은 막대 시각화 차용 — 체온이 실제 게임 변수(Q7 C)이므로 중심 시각 요소로 격상.

### HUD 구성 (1280×800 기준 우측 ~110px ≈ 8.6% 폭)

1. **체온 막대 (메인)**
   - 색상 영역: 🔵 저체온 (33~35.5℃) / 🟢 적정 (35.5~37.5℃) / 🔴 고체온 (37.5~40℃)
   - 눈금: 33 · 35 · 35.5 · 36.5 · 37.5 · 38 · 40
   - 슬라이더(◀): 현재 체온 위치, 환경/액션에 따라 실시간 상승·하강 트윈
   - readout: "35.8℃ — 저체온 진입!" 같은 수치+라벨

2. **보조 인디케이터** (막대 아래)
   - 🩸 혈관: ▼ 수축 / ▲ 확장 (텍스트 chip)
   - 💧 땀: 0~100% 게이지
   - ⚗️ 티록신: 0~100% 게이지 (느리게 차오름 → 신경/호르몬 시간차 시각화)

3. **변화 로그** (HUD 하단)
   - "방금: 떨림 발생 / 다음: 티록신 효과 (느림)" — 즉시 반응과 느린 반응 대비

4. **토스트 알림** (게임 영역 상단 중앙, 변화 순간만)
   - 예: "🩸 혈관 수축! 체온 방어 시작" / "💧 땀 분비 시작! 기화열로 발산"

### 학습 효과
- 환경 전환(시내 ↔ 사우나) 시 슬라이더가 적정 녹색대에서 위·아래로 흔들리는 걸 학생이 시각적으로 추적
- 토스트는 즉시(신경 반응), 티록신 게이지는 천천히 차오름 → **신경/호르몬 빠름·느림 대비**가 메커니즘 자체로 학습됨
- 체온 슬라이더가 녹색대를 벗어나면 → Q7 C의 자동 회복 트리거

## 3-2. ✅ Q6 — 이동 중 학습 이벤트 + 전체 게임 아크

**A 간소형의 정제판** — 공항을 "비행기표 = 퀴즈 게이트"로 만들어 학습 비트 분산.

### 전체 게임 흐름 (2국 미션 기준)

| # | 단계 | 학습/메커니즘 |
|---|---|---|
| 1 | 🏫 시작: 학교 교실 — 학급 회의 | 추운 나라 2개 중 1개 선택, 더운 나라 2개 중 1개 선택 → 각각 NPC와 **가위바위보 2회 (분리)** → 승: 본인 선택 / 패: NPC 선택 |
| 2 | ✈️ 출발국 공항 | 퀴즈 1문항 정답 → 비행기표 → 월드맵 비행기 컷씬 → 1국 도착 |
| 3 | 🏔️ 1국 (추운 나라) 야외 | 추위 관련 미니 액션 (떨림 / 혈관 수축 / 티록신 ↑ 시각화) |
| 4 | ♨️ 1국 실내 (사우나·찜질방) | 야외와 정반대 (혈관 확장 / 땀 / 기화열) |
| 5 | ✈️ 1국 공항 | 퀴즈 1문항 → 컷씬 → 2국 도착 |
| 6 | 🏜️ 2국 (더운 나라) 야외 | 더위 관련 미니 액션 (땀 / 혈관 확장) |
| 7 | ❄️ 2국 실내 (실내 스키장·워터파크) | 야외와 정반대 (떨림 / 혈관 수축) |
| 8 | ✈️ 2국 공항 → 귀환 | 퀴즈 1문항 → 컷씬 → 출발국 |
| 9 | 🏫 교실 결말 | "수학여행에서 체온 조절(항상성)의 중요성을 알게 되었다" 멘트 + 결말 일반화 |

### 핵심 메커니즘
- **가위바위보 ② 분리 2회**: 추 따로, 더 따로 → 결과 4가지 조합 (내A내X / 내A NPCY / NPCB내X / NPCB NPCY) → 친구 간 비교 다양성 ↑
- **공항 퀴즈 1문항 게이트**: 총 3공항 × 1문항 = 3문항 분산
- **자동차/도보 이동**: 별도 학습 이벤트 없음 (짧은 트윈 또는 즉시 전환)
- **비행기 이동**: 월드맵 위 비행기 아이콘 컷씬 (인터랙션 없음)

### 추후 확장 (post-MVP) — Q10 시드
국가별 **문화 미니 이벤트 1개씩** (예: 이집트 야외 = 더위 활동 + 피라미드/스핑크스 퍼즐, 핀란드 야외 = 추위 활동 + 오로라/순록 미니 이벤트). 우선은 체온 조절 뼈대만 완성하고, 그 다음에 국가별 문화 요소를 추가하는 방식.

## 3-4. ✅ Q8 — 비주얼 톤 + 캐릭터/맵 스타일

**B 원안 도트 RPG** 확정. 사용자가 도트 자산 직접 제작.

### 자매 도트 게임(snug-hormone-game, pizza-expedition) 답습 규격

| 항목 | 규격 |
|---|---|
| 화면당 배경 | 1280×800 단일 도트 일러스트 PNG 1장 |
| 캐릭터 sprite | ~110×186 픽셀 (5등신), idle 1프레임 + 4방향 walk 각 5프레임 (snug-hormone-game 기준) |
| 맵 구조 | 타일맵 없음 — 배경 위 sprite 오버레이, 노드 사이 L자 경로 이동 |
| 동적 효과 | Phaser 파티클로 눈·김·땀·오로라 등 오버레이 |
| 좌표 편집 | `?admin=1` 시각 편집 모드로 노드 드래그 (pizza-expedition 회고 반영) |

### 캐릭터
- **새로 제작** — 수학여행 가는 학생 컨셉 (이 게임 전용 주인공)
- snug-hormone-game school_girl과 다른 새 캐릭터, 동일 규격 권장

### 자산 추산 (4국 모두 자유 방문 가능 기준)
- 배경: 1교실 + 1출발국공항 + 1월드맵 + 4국×(공항·야외·실내) = **15장**
- 플레이어 sprite 1세트 (idle + 4방향 walk)
- NPC 초상화/sprite 약간 (학급 친구 4, 환경 가이드 NPC 약간)
- UI: 비행기, 손난로, 부채 등 소품 아이콘 약간

## 3-3. ✅ Q7 — 미션 성공/실패 메커니즘

**C 체온 게이지 시스템 (위험 시 경고만, 게임오버 없음)** 선택.

### 메커니즘
- 체온이 실제 게임 변수 (HUD 막대의 슬라이더 값)
- 환경/액션에 따라 실시간 상승·하강
- 위험 범위(저체온 < 35.5℃ 또는 고체온 > 37.5℃) 진입 → 토스트 경고 + NPC 도움 / 자동 회복 유도
- **게임오버 없음** — 모든 학생이 결말까지 도달 보장
- 결말 평가: 체온 유지율 + 퀴즈 정답률 → ⭐ 별점 + 격려 메시지

### 공항 퀴즈 1문항 오답 처리 (학생 답변 반영)
- 1문항 출제 → 오답이면 다른 문항 1개 더 출제
- 또 오답이면 또 다른 문항... **정답 나올 때까지 문제풀이 반복**
- 결과: 학생이 반드시 한 번은 정답을 맞춰야 통과 → 학습 강화 + 좌절 ↓ (영구 막힘 없음)

### 학습 + 게임 메커니즘 통합 효과
- 항상성의 정의("정상 범위 유지")가 게임 메인 변수와 일치 → 메타학습
- 학생이 HUD 슬라이더를 들여다볼 동기 ↑
- 결말 별점이 자기 평가 도구가 됨 (재플레이 동기)

- **Phaser**: 세계지도 + 국가 내부 맵 + 캐릭터 sprite + 이동 트윈
- **React 오버레이**: 대화 박스, 퀴즈, 학습 정리 카드, HUD(체온/혈관/땀/티록신)
