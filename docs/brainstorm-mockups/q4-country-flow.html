Q4 — 한 국가 방문 흐름 구조

예시: 핀란드 (추운 나라 + 사우나) — 한 번 방문하는 동안 어떤 단계를 거칠까요?

A

압축형 — 1국가 = 3 stops (학습 비트 2개)Claude 추천

야외 한 곳에서 신경+호르몬 반응을 시간 경과로 함께 다루고, 실내 패러독스에서 반대 반응을 학습.

✈️ 공항 도착도입 컷씬
→
🏔️ 시내 광장 (-15℃)몸 떨림 + 혈관 수축
잠시 후 티록신 분비 증가학습: 추운 환경 신경+호르몬 반응
→
♨️ 사우나 (90℃)혈관 확장 + 땀 분비학습: 환경 반전 시 항상성
→
✈️ 출국학습 정리 카드
⏱ 1국가 ≈ 5분 · 2국가 클리어 ≈ 10분 · 4국가 ≈ 20분 · 콘텐츠 작성 부담 낮음
B

분리형 — 1국가 = 4 stops (학습 비트 3개)

야외를 두 곳으로 나누어 신경 반응과 호르몬 반응을 또렷이 분리. 실내 패러독스에서 반대 반응.

✈️ 공항
→
🏔️ 시내떨림+혈관 수축신경 반응
→
❄️ 호숫가티록신 ↑ → 세포 호흡 ↑호르몬 반응
→
♨️ 사우나혈관 확장+땀반대 환경 반응
→
✈️ 출국
⏱ 1국가 ≈ 7~8분 · 2국가 클리어 ≈ 15분 · 4국가 ≈ 30분 · 콘텐츠 작성 부담 중간
C

왕복형 — 1국가 = 5 stops (학습 비트 3개)

야외 → 실내 → 다시 야외 복귀 까지 다뤄, "추위 → 더위 → 추위" 의 이중 항상성 전환을 강조.

✈️ 공항
→
🏔️ 시내 (-15℃)떨림+혈관 수축, 티록신추운 환경 반응
→
♨️ 사우나 (90℃)혈관 확장+땀더운 환경 반응
→
🏔️ 시내 복귀다시 추위 반응전환 항상성
→
✈️ 출국
⏱ 1국가 ≈ 8~10분 · 2국가 클리어 ≈ 18분 · 4국가 ≈ 36분 · 콘텐츠 작성 부담 중상
💡 더운 나라(예: 두바이)는 색이 반전됩니다: 야외(더위) → 실내 스키장(추위) → (C라면) 야외 복귀.
💡 시간 경과 = 시각 효과(캐릭터 옆에 떨림→땀→안정 등으로 표현). 실시간 30초 이내로 압축.
